# HARD — Soal 03: Ubah Warna Background Acak

## Instruksi

Ada sebuah tombol **"Warna Acak!"**.  
Setiap kali diklik, background halaman berubah ke **warna acak** yang berbeda.  
Tampilkan juga **kode warna** yang sedang aktif, contoh: **"Warna saat ini: #a3f2bc"**

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `document.body.style.backgroundColor`
- Gunakan `innerText` untuk menampilkan kode warna
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Setiap kali diklik:**

```
[Background berubah ke warna acak]
Warna saat ini: #f3a2c1
```
