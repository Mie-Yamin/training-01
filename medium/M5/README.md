# MEDIUM — Soal 05: Kalkulator Tambah Sederhana

## Instruksi

Ada dua input angka dan satu tombol **"Hitung"**.  
Saat tombol diklik, tampilkan hasil penjumlahan kedua angka tersebut.

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `.value` untuk membaca isi input
- Gunakan `innerText` untuk menampilkan hasil
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Input: 5 dan 3, lalu klik Hitung:**
```
Hasil: 8
```

**Input: 10 dan 20, lalu klik Hitung:**
```
Hasil: 30
```
