# MEDIUM — Soal 02: Validasi Input Nama

## Instruksi

Ada sebuah input teks dan sebuah tombol **"Cek Nama"**.

- Jika input **kosong** saat tombol diklik → tampilkan **"Nama tidak boleh kosong!"**
- Jika input **diisi** → tampilkan **" Halo, [nama yang diisi]!"**

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `.value` untuk membaca isi input
- Gunakan `innerText` untuk menampilkan hasil
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Jika klik tanpa isi nama:**

```
Nama tidak boleh kosong!
```

**Jika nama diisi "Rina" lalu klik:**

```
Halo, Rina!
```
