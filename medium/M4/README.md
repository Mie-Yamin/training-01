#  MEDIUM — Soal 04: Ubah Tema Halaman

##  Instruksi

Ada dua tombol: **"Mode Gelap"** dan **"Mode Terang"**.  
- Klik **"Mode Gelap"** → background halaman menjadi **hitam**, teks status menjadi **"Mode Gelap Aktif"**
- Klik **"Mode Terang"** → background halaman menjadi **putih**, teks status menjadi **"Mode Terang Aktif"**

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText` untuk teks status
- Gunakan `document.body.style.backgroundColor` untuk mengubah background halaman
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Setelah klik "Mode Gelap":**
```
[Halaman jadi hitam]
Mode Gelap Aktif
```

**Setelah klik "Mode Terang":**
```
[Halaman jadi putih]
Mode Terang Aktif
```
