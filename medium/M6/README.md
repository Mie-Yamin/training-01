# MEDIUM — Soal 06: Tebak Angka

## Instruksi

Ada sebuah input dan tombol **"Tebak!"**.  
Angka rahasianya adalah **7**.  
- Jika tebakan **benar** → tampilkan **"Benar! Kamu menebak dengan tepat!"**
- Jika tebakan **salah** → tampilkan **"Salah! Coba lagi."**

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `.value` dan `Number()` untuk membaca input
- Gunakan `innerText` untuk menampilkan hasil
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Input: 5, klik Tebak:**
```
Salah! Coba lagi.
```

**Input: 7, klik Tebak:**
```
Benar! Kamu menebak dengan tepat!
```
