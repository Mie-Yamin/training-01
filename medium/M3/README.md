#  MEDIUM — Soal 03: Penghitung Mundur

## Instruksi

Ada sebuah angka **10** yang ditampilkan dan sebuah tombol **"Kurangi"**.  
Setiap kali tombol diklik, angka berkurang 1.  
Jika angka sudah **0**, tampilkan teks **" Liftoff!"** dan tombol tidak boleh bisa diklik lagi.

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText`
- Untuk menonaktifkan tombol, gunakan `.disabled = true`
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Awal:**
```
10
[ Kurangi ]
```

**Setelah diklik beberapa kali (misal sampai 0):**
```
Liftoff!
[ Kurangi ]  ← (tidak bisa diklik)
```
