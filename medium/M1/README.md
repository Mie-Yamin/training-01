#  MEDIUM — Soal 01: Toggle Teks

##  Instruksi

Ada sebuah teks dan sebuah tombol **"Sembunyikan"**.  
- Saat tombol diklik **pertama kali** → teks hilang, tombol berubah jadi **"Tampilkan"**
- Saat tombol diklik **lagi** → teks muncul kembali, tombol berubah kembali jadi **"Sembunyikan"**

Dan seterusnya bergantian (toggle).

---

##  Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText` (untuk teks konten DAN label tombol)
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Awal:**
```
Ini teks yang bisa disembunyikan.
[ Sembunyikan ]
```

**Setelah klik pertama:**
```
(kosong)
[ Tampilkan ]
```

**Setelah klik kedua:**
```
Ini teks yang bisa disembunyikan.
[ Sembunyikan ]
```
