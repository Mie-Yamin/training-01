# MEDIUM — Soal 07: Ubah Ukuran Teks

## Instruksi

Ada sebuah teks dan dua tombol: **"Perbesar"** dan **"Perkecil"**.

- Setiap klik **"Perbesar"** → ukuran font bertambah **2px**
- Setiap klik **"Perkecil"** → ukuran font berkurang **2px** (minimum 10px)
- Tampilkan ukuran font saat ini di elemen status

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `.style.fontSize` untuk mengubah ukuran
- Gunakan `innerText` untuk status
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Awal (font 16px):**

```
Ukuran teks ini bisa diubah!
Ukuran saat ini: 16px
[ Perbesar ]  [ Perkecil ]
```

**Setelah klik Perbesar 2x (font 20px):**

```
Ukuran teks ini bisa diubah!
Ukuran saat ini: 20px
```
