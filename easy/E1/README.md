# 🟢 EASY — Soal 01: Sapa Dunia!

## Instruksi

Di halaman ini sudah ada sebuah tombol dan sebuah teks kosong.  
Tugasmu adalah membuat teks berubah menjadi **"Hello, World!"** saat tombol diklik.

---

## Aturan

- Gunakan `getElementById` untuk mengambil elemen
- Gunakan `addEventListener` untuk mendeteksi klik
- Gunakan `innerText` untuk mengubah teks
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Sebelum diklik:**

```
[ Tampilkan Pesan ]

(teks kosong)
```

**Setelah diklik:**

```
[ Tampilkan Pesan ]

Hello, World!
```
