# EASY — Soal 02: Ganti Nama

## Instruksi

Di halaman ini ada sebuah `<h1>` bertuliskan **"Nama: ???"** dan sebuah tombol.  
Saat tombol diklik, ubah teks tersebut menjadi **"Nama: Budi"**.

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText`
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Sebelum diklik:**

```
Nama: ???
[ Isi Nama ]
```

**Setelah diklik:**

```
Nama: Budi
[ Isi Nama ]
```
