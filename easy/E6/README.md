#  EASY — Soal 06: Ganti Isi Paragraf

##  Instruksi

Ada sebuah paragraf dengan teks **"Ini adalah teks awal."** dan sebuah tombol.  
Saat tombol diklik, ubah isi paragraf menjadi **"Teks sudah diganti oleh JavaScript!"**.

---

##  Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText`
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Sebelum diklik:**

```
Ini adalah teks awal.
[ Ganti Teks ]
```

**Setelah diklik:**

```
Teks sudah diganti oleh JavaScript!
[ Ganti Teks ]
```
