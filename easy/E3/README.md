# EASY — Soal 03: Hitung Klik

## Instruksi

Buat sebuah penghitung sederhana.  
Setiap kali tombol diklik, angka yang tampil harus **bertambah 1**.

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText` untuk membaca dan mengubah angka
- **Jangan** ubah apapun di bagian HTML

---

## Output yang Diharapkan

**Sebelum diklik:**

```
Jumlah Klik: 0
[ Klik Saya! ]
```

**Setelah diklik 3x:**

```
Jumlah Klik: 3
[ Klik Saya! ]
```
