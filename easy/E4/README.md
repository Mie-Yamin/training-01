# EASY — Soal 04: Sembunyikan Teks

## Instruksi

Ada sebuah teks bertuliskan **"Teks ini bisa disembunyikan!"** dan sebuah tombol **"Sembunyikan"**.  
Saat tombol diklik, teks tersebut harus **menjadi kosong** (menghilang).

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText` untuk mengosongkan teks
- **Jangan** ubah apapun di bagian HTML

---

##  Output yang Diharapkan

**Sebelum diklik:**

```
Teks ini bisa disembunyikan!
[ Sembunyikan ]
```

**Setelah diklik:**

```
(teks kosong / tidak terlihat)
[ Sembunyikan ]
```
