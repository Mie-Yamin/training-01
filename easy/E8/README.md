#  EASY — Soal 07: Tampilkan Tanggal

##  Instruksi

Ada sebuah teks kosong dan sebuah tombol **"Lihat Tanggal"**.  
Saat tombol diklik, tampilkan teks statis **"Hari ini: Senin"** di dalam elemen tersebut.

---

## Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `innerText`
- **Jangan** ubah apapun di bagian HTML
- Cukup tampilkan teks statis "Hari ini: Senin" (tidak perlu tanggal dinamis)

---

##  Output yang Diharapkan

**Sebelum diklik:**
```
[ Lihat Tanggal ]

(kosong)
```

**Setelah diklik:**
```
[ Lihat Tanggal ]

Hari ini: Senin
```
