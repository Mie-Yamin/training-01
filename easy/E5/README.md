#  EASY — Soal 05: Ubah Warna Teks

##  Instruksi

Ada sebuah teks **"JavaScript itu seru!"** dan sebuah tombol.  
Saat tombol diklik, ubah warna teks tersebut menjadi **merah**.

---

##  Aturan

- Gunakan `getElementById`
- Gunakan `addEventListener`
- Gunakan `.style.color` untuk mengubah warna
- **Jangan** ubah apapun di bagian HTML

---

##  Output yang Diharapkan

**Sebelum diklik:**

```
JavaScript itu seru!   ← warna hitam biasa
[ Warnai Merah ]
```

**Setelah diklik:**

```
JavaScript itu seru!   ← warna MERAH
[ Warnai Merah ]
```
